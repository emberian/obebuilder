# obebuilder

A harness for building research software with several model families at once, under a
systems-engineering discipline: every unit of work names the specification it refines and the
oracle outside its author that can refute it; work is a DAG of small nodes with gates
(brief review, implementation, verification by a different family, measurement, merge); a
local visualizer shows what every agent is doing; a ledger records every decision.

Read `DESIGN.md`. First consumer: `~/dev/obend`.
